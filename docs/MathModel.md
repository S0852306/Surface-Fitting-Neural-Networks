This document presents the mathematical formulation of neural networks. A thorough understanding of the model is essential for deploying a trained network on real\-time hardware. The following surface fitting task serves as a running example:

# Notations

**Bold letters** represent vectors or matrices.


 $\mathit{\mathbf{x}}\in R^{N\times 1}$ : input variable, an $N\times 1$ column vector, where $N$ is the input dimension.


 $\mathit{\mathbf{Y}}\in R^{M\times 1}$ : output of the network, an $M\times 1$ column vector, where $M$ is the output dimension.


 $\sigma :R^{\nu \;} \to R^{\nu \;}$ : activation, a point\-wise nonlinear function, $\nu \in Z$ (arbitrary positive integer, depends on "`LayerStruct`").


 $d$: depth of the network, an integer scalar.


 ${\mathit{\mathbf{W}}}_k$: weight matrices, ${\mathit{\mathbf{b}}}_k$: bias vectors, $k=1,2,\ldotp \ldotp \ldotp ,d$ 

<a id="H_9D8371FF"></a>

# Mathematical Representation of Neural Networks

(for regression / surface fitting tasks)

 $$ {\mathit{\mathbf{h}}}_0 =\mathit{\mathbf{x}} $$ 

 $$ {\mathit{\mathbf{h}}}_k =\sigma \;\left({\mathit{\mathbf{W}}}_k {\mathit{\mathbf{h}}}_{k-1} +{\mathit{\mathbf{b}}}_k \right),k\in Z,k\le d $$ 

 $$ \mathit{\mathbf{y}}={\mathit{\mathbf{W}}}_d {\mathit{\mathbf{h}}}_{d-1} +{\mathit{\mathbf{b}}}_d $$ 

 $$ \mathit{\mathbf{y}}=\textrm{NN}\left(\mathit{\mathbf{x}}\right),\;\textrm{NN}\left(\mathit{\mathbf{x}}\right):R^N \to R^M $$ 

## Optimizable Spline Activation

In the standard model, $\sigma$ is a fixed function (e.g. Gaussian $e^{-z^2}$). NeuralNetsPack also supports a **learnable B\-spline activation** where the nonlinearity itself is optimized during training:

 $$ \sigma(z) = \sum_{i=1}^{n_b} c_i \, B_i^{(k)}(z) $$ 

$B_i^{(k)}$ are B\-spline basis functions of order $k$ defined on a uniform knot grid, and $\mathit{\mathbf{c}}=[c_1,\ldots,c_{n_b}]^T$ are learnable coefficients. These are optimized jointly with all $\mathit{\mathbf{W}}_k, \mathit{\mathbf{b}}_k$ via gradient descent.

This allows each hidden unit to adapt its nonlinearity to the data, achieving higher accuracy on sharp or nonsmooth targets without increasing network depth.

# A Step\-by\-Step Example

The layer\-by\-layer forward computation of the trained network is detailed below. 


Goal: compute $\textrm{NN}\left(\left\lbrack \begin{array}{c} x\newline y \end{array}\right\rbrack =\left\lbrack \begin{array}{c} 0\ldotp 2\newline 0\ldotp 5 \end{array}\right\rbrack \right)\approx {\left(0\ldotp 2\right)}^2 +{\left(0\ldotp 5\right)}^2 =0\ldotp 29$ 


Computation of first layer:

 $$ {\mathit{\mathbf{h}}}_0 =\left\lbrack \begin{array}{c} 0\ldotp 2\newline 0\ldotp 5 \end{array}\right\rbrack $$ 

 $$ {\mathit{\mathbf{h}}}_1 =\sigma \;\left({\mathit{\mathbf{W}}}_1 {\mathit{\mathbf{h}}}_0 +{\mathit{\mathbf{b}}}_1 \right) $$ 

 $$ {\mathit{\mathbf{h}}}_1 =\sigma \;\left(\left\lbrack \begin{array}{cc} w_{11}  & w_{12} \newline w_{21}  & w_{22} \newline w_{31}  & w_{32}  \end{array}\right\rbrack \left\lbrack \begin{array}{c} 0\ldotp 2\newline 0\ldotp 5 \end{array}\right\rbrack +\left\lbrack \begin{array}{c} b_1 \newline b_2 \newline b_3  \end{array}\right\rbrack \right)=\left\lbrack \begin{array}{c} \sigma \;\left({0\ldotp 2w}_{11} +{0\ldotp 5w}_{12} +b_1 \right)\newline \sigma \;\left({0\ldotp 2w}_{21} +0\ldotp 5w_{22} +b_2 \right)\newline \sigma \;\left({0\ldotp 2w}_{31} +0\ldotp 5w_{32} +b_3 \right) \end{array}\right\rbrack $$ 

Remark: the notation $w_{\textrm{ij}} ,b_i$ is reused across layers for brevity; 


**the parameters of** $\mathit{\mathbf{W}}_1 ,{\mathit{\mathbf{W}}}_2 ,{\mathit{\mathbf{W}}}_3$ **and** ${\mathit{\mathbf{b}}}_1 ,{\;\mathit{\mathbf{b}}}_{2,} {\;\mathit{\mathbf{b}}}_3$ **are distinct across layers**.

```matlab

h1=NN.active(NN.weight{1}*h0+NN.bias{1}) % h1=sigma(W1*h0+b1)
```

# **Preprocessing**

Preprocessing is critical for training neural networks; without it, solvers may fail to converge or yield poor accuracy. This package provides a built\-in normalization method.


Readers familiar with preprocessing may proceed to the next section; the full computation model is stated above.


Otherwise, use `"NN.InputAutoScaling"` or  `"NN.LabelAutoScaling"` for standard normalization.

```matlab
% NN.InputAutoScaling='on'; 
% NN.LabelAutoScaling='on';
```

Normalization is defined as follows. Given a data set:

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; $$ y=f\left(x\right)=\sin \left(x\right),x\in \left\lbrack 0,2\pi \right\rbrack $$ 

Note: this example is for illustration only; normalization has negligible effect here. 

```matlab
x=linspace(0,2*pi,10); y=sin(x);
```

Normalization formula:


Let $x^{\prime }$ denote the normalized data:


 $x^{\prime } =\frac{x-\mu_x \;}{\sigma_x \;}\;$, where $\mu_x \;$ and $\sigma_x \;$ are the mean and standard deviation of $x$.


Before normalization:

```matlab
x
```

```matlabTextOutput

         0    0.6981    1.3963    2.0944    2.7925    3.4907    4.1888    4.8869    5.5851    6.2832

```


After normalization:

```matlab
xNormalized=(x-mean(x))/std(x)
```

```matlabTextOutput

   -1.4863   -1.1560   -0.8257   -0.4954   -0.1651    0.1651    0.4954    0.8257    1.1560    1.4863
```

This normalization formula is the same for output data $y$:

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; $$ y^{\prime } =\frac{y-\mu_y }{\sigma {\;}_y } $$
